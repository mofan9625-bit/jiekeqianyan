在日常办公中，面对动辄数万行、包含空值与混乱格式的 Excel 原始数据表，人工编写 VLOOKUP 或透视表耗时耗力。借助 ChatGPT 的代码沙箱与 Claude 的长文本能力，你可以实现全自动 Excel 处理。

---

### 一、ChatGPT 处理 Excel 的三大实战场景

```mermaid
graph LR
    A[拖入原始 Excel] --> B[ChatGPT 自动编写 Python 清洗]
    B --> C[生成透视表与交互热力图]
    C --> D[导出清洗后的 Excel 供下载]
```

1. **自动清洗异常值与空值**：将文件拖入对话框，提示：“*检查表格中 B 列的缺失值并用均值填充，删除重复的身份证号行*”。
2. **生成复杂 VBA / 公式**：不用死记硬背公式，直接说明业务逻辑，AI 即可生成准确的 Excel 公式或一键运行的 VBA 宏代码。

---

### 二、Claude 处理超大文本与报表分析

对于包含大量文字备注或长篇账单数据的表格，Claude 凭借其超大上下文窗口，能够直接解读表格背后的商业趋势。

* **提示词范例**：
  > “请分析这份季度销售明细表，找出净利润下滑最严重的 3 个产品线，并用 Markdown 表格列出下滑原因与改进建议。”

---

### 三、AI 自动化 Excel 工作流实操守则

* **隐私数据脱敏**：在将表格上传至大模型前，切记将客户姓名、手机号、财务秘钥等敏感字段进行掩码处理（如用 `用户A` 替代真实姓名）；
* **结果人工复核**：始终抽查 5%-10% 的计算公式与汇总结果，防止模型幻觉造成计算偏差。
